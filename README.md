# 🧠 AI Prompt Saver – Chrome Extension

**AI Prompt Saver** is a simple and intuitive Chrome Extension that allows users to **save**, **edit**, **copy**, **reorder**, **delete**, **backup**, and **restore** their frequently used AI prompts – all within a sleek popup UI.

> Pin this extension to your Chrome toolbar and access all your saved prompts in seconds—no more rewriting or copy-pasting from elsewhere.


---

## 🚀 Features

- ✅ Save and name unlimited prompts  
- ✅ Edit or delete saved prompts anytime  
- ✅ Copy prompt text with a single click
- ✅ Drag & drop to reorder your prompts  
- ✅ Local backup and restore functionality (JSON file)  
- ✅ Minimal, clean, responsive UI  
- ✅ No internet required, data stored via Chrome Sync API

---

## 📦 Installation

1. Clone or download this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/ai-prompt-saver.git
   
2. Open Google Chrome and navigate to: chrome://extensions/
3. Enable Developer mode (top right).
4. Click Load unpacked and select the project folder.
5. Done! The extension icon will appear in your toolbar.
